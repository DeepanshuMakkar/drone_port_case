# Drone Interception Case Study & Coding Tasks

This repository contains three components:

1️⃣ **C++ Task** 
2️⃣ **Python Task** 
3️⃣ **Drone Catching Case Study** 


---

Run 

For CPP task

```bash
cd cpp
mkdir -p build
cd build
cmake ..
cmake --build .
```

For Python task

```bash
python3 python/task.py
```

For Drone Port case study
Open drone_port_case_study folder and there will be a pdf where the proposed solution to the case study is given
